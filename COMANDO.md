# 📋 El comando para tu equipo

Cópiale este mensaje a cada persona. Solo tienen que **pegarlo en el chat de
Claude Code** (en cualquier carpeta) y Claude hace el resto.

```
Instala la Fábrica de Contenido Easy Meli: clona
https://github.com/EasyMeli/easymeli-contenido en esta carpeta, lee su archivo INSTALAR.md
y ejecútalo tal cual (deja la skill lista, crea mi carpeta de trabajo,
instala las dependencias) y después sigue con el onboarding. Háblame en
simple y no me mandes a la Terminal.
```

## Acceso (el repo es público)
El repositorio vive en `github.com/EasyMeli/easymeli-contenido` y es **público**:
cualquiera puede clonarlo **sin cuenta de GitHub y sin invitaciones**. Solo pega
el comando y listo.

Si algún día quieres cerrarlo, en GitHub → Settings → Danger Zone puedes volverlo
privado (ahí sí habría que invitar a cada persona).

## Para quien YA lo tenía (traer los últimos cambios)

Si alguien ya había instalado el proyecto y saqué mejoras nuevas, que **abra
Claude Code en la carpeta del proyecto** y pegue esto:

```
Actualiza la Fábrica de Contenido Easy Meli: trae los últimos cambios del
repositorio y sigue su archivo ACTUALIZAR.md (actualiza la skill y el código
de mi carpeta de trabajo) SIN borrar mis fotos, mi clave ni mi voz. Háblame
en simple y no me mandes a la Terminal.
```

Sus datos personales (fotos, clave de Gemini, voz, biblioteca, temas) **no se
tocan**: viven aparte y están protegidos. Solo se actualiza el código.

## Qué necesita tener la persona (una sola vez)
- **Claude Code** instalado.
- **git** (viene en Mac; en Windows: git-scm.com).
- **Node** y **Python** — si le faltan, Claude le pasa el link en el momento.

Nada más. No baja ZIP, no descomprime, no abre la Terminal.
